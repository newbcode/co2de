# Terminal Visualization Skill

탄소 배출량 데이터를 터미널에서 직관적이고 임팩트 있게 시각화한다.

## 시각화 컴포넌트

### 1. 세션 요약 배너

세션 종료 시 표시하는 컴팩트 요약:

```
┌─────────────────────────────────────────┐
│  🌍 co2de — 이번 세션 탄소 발자국        │
│                                         │
│  토큰: 45,230  │  CO2: 2.14g            │
│  ████████░░░░░░░░  스마트폰 0.27회 충전   │
│                                         │
│  🌳 나무 한 그루가 3.5초면 흡수하는 양     │
└─────────────────────────────────────────┘
```

### 2. 컬러 코딩 시스템

배출량 수준에 따른 색상 그라데이션:

| 수준 | CO2 범위 | 색상 | 의미 |
|------|---------|------|------|
| 저 | 0~1g | 초록 (green) | 가벼운 세션 |
| 중 | 1~10g | 노랑 (yellow) | 보통 세션 |
| 고 | 10~50g | 주황 (orange) | 무거운 세션 |
| 극고 | 50g+ | 빨강 (red) | 매우 무거운 세션 |

### 3. 바 차트

수평 막대로 배출량 시각화:

```
CO2  ████████████░░░░░░░░  2.14g
비교  구글검색 ×10.7 | 넷플릭스 3.6분
```

### 4. 누적 대시보드

히스토리 데이터가 있을 때 표시:

```
최근 7일 탄소 배출량
월 ██░░░░░░░░  1.2g
화 ████░░░░░░  3.8g
수 ██████████  9.1g  ← 오늘
목 ░░░░░░░░░░  -
```

### 5. 비유 시각화

숫자 대신 직관적 비유로 표현:

```
🌳 나무 한 그루가 3.5초면 흡수
🚗 자동차로 18m 주행한 것과 같은 양
📱 스마트폰 0.27회 충전
🔍 구글 검색 10.7회
```

## 구현 원칙

1. **임팩트 우선** — 숫자만 나열하지 말고 감정에 호소하는 비유 표현을 항상 포함
2. **터미널 호환성** — chalk/ansi-colors 등 라이브러리로 색상 처리, NO_COLOR 환경변수 존중
3. **반응형 레이아웃** — 터미널 너비 감지하여 80열 미만이면 컴팩트 모드
4. **비침습적** — 바이브코딩 흐름을 끊지 않는 간결한 출력. 상세 정보는 별도 명령으로
5. **유니코드 폴백** — 이모지 미지원 터미널에서는 텍스트로 대체

## 렌더링 전략

```
데이터 수신 (CarbonResult)
    ↓
터미널 환경 감지 (너비, 색상 지원, 유니코드)
    ↓
적절한 렌더러 선택 (풀/컴팩트/텍스트전용)
    ↓
문자열 조립 및 출력
```

## 테스트 케이스

1. 풀 사이즈 출력 — 120열 터미널에서 정상 렌더링
2. 컴팩트 출력 — 60열 터미널에서 잘림 없이 렌더링
3. 노컬러 모드 — NO_COLOR=1 환경에서 ANSI 코드 없는 출력
4. 제로 데이터 — 0 토큰일 때 적절한 안내 메시지
5. 극대 데이터 — 100만 토큰일 때 숫자 포맷팅 정상 (1,000,000)
