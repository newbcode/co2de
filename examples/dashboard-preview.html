three pillars · prompt · response · cache · Mamun 2026 (R²≈0.44)
prompt
Name, don't describe
×"the function that handles auth and validates the token"
✓"validateAuthToken() in src/auth.ts"
Symbol refs stay tiny. Vague descriptions force the agent to grep, read, and guess — each step pays full prefill on the same model.
prompt
Drop role preambles
×"You are an expert TypeScript engineer. Carefully..."
✓direct task, no preamble
50–200 tokens × every prompt. Agentic loops don't gain measurable quality from role preambles past turn 1.
more techniques · apply to any session
prompt
Reference, don't paste
×paste 200 lines of the same file each turn
✓"src/auth.ts:40-60" · stable files → CLAUDE.md
Files in CLAUDE.md ride the cache every turn at 10% energy. Pasted content pays full prefill on each turn.
response
Show, don't regenerate
×"regenerate this, make it more robust"
✓"add null check on line 42, keep everything else"
Surgical edits reuse cached context. Re-rolls recompute the whole function from scratch on the same model.
response
Constrain the answer
×"explain what's wrong with this code"
✓"one-line diff, no prose, no preamble"
Output tokens always cost full energy; prose has no cache discount. Shape the answer to what you actually need.
cache
Batch adjacent asks
×3 separate "also, can you..." follow-ups
✓numbered list · one turn · "1) ... 2) ... 3) ..."
Each new turn pays prefill again — tools + system + history re-processed. Consolidating keeps the cache working.
cache
Keep CLAUDE.md stable
×edit CLAUDE.md mid-session to add instructions
✓settle CLAUDE.md before coding · treat as cache-resident
CLAUDE.md content is prefixed to every turn. Changes invalidate the cache; stability keeps every turn on the 10%-energy cache path.
cache
Stay in one session
×/clear or restart between related tasks
✓keep related work in one chat · 5-min cache TTL
Each new session pays full prefill on system prompt + tools + CLAUDE.md. Cache window reopens when you stay.
