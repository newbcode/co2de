Methodology
Calculation Pipeline
CO₂ (gCO₂e) = (tokens x Wh/token x PUE) / 1000 x carbon_intensity Where: tokens = input + output + cache_read + cache_write Wh/token = model-specific (see table below) PUE = 1.2 (datacenter overhead multiplier) carbon_intensity = 390 gCO₂/kWh (US)

Token count explains ~44% of energy variance (R²≈0.44). Inference time is a stronger predictor but unavailable via API.
